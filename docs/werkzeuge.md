# Verwendete Werkzeuge, Open Source und KI

Die Challenge verlangt, dass wir das offenlegen. Bei jedem neuen Werkzeug oder
jeder neuen Bibliothek hier eintragen.

## Plattform

| Werkzeug | Wofür | Stand vor dem Hackathon |
| -------- | ----- | ----------------------- |
| Hazu (hazu.app) | Inhalte, Rechte, Hosting der Welt | bestehend |
| Hazu World | 3D-Engine: Laufen, Figuren, Level-Builder, Genius-Anbindung | bestehend |
| Hazu Widget-Bridge (`hazu-api.js`) | Daten und KI aus den Stationen | bestehend |
| Hazu Genius | KI-Coach und KI-Feedback in den Stationen | bestehend |

## KI-Tools beim Entwickeln

| Werkzeug | Wofür |
| -------- | ----- |
| Claude (Claude Code) | Setup, Doku, Code der Stationen |
| ChatGPT | Personas, Inhalte, Code der Stationen |
